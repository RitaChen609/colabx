# ColabX 2026 Hackathon Project

Performance Pipeline Pulse is a read-only dashboard for monitoring the latest
Performance Engineering pipeline coverage. Its Express API queries the MarkLogic
statistics database used by `marklogic-perfRunStatus`, and its Vite React frontend
displays the resulting coverage cells.

See [backend/README.md](backend/README.md) and [frontend/README.md](frontend/README.md)
for local run instructions.
